# المتميز لاب — منصة إدارة التحاليل الطبية

موقع لإدارة الدكاترة ومعامل التحاليل والمرضى ونتائج التحاليل (PDF)، مبني بـ **Next.js 14 (App Router)** و **Tailwind CSS** بأسلوب **shadcn/ui**، بالكامل باللغة العربية واتجاه RTL.

## المميزات

- **حساب الأدمن**: إضافة/تعديل/حذف الدكاترة ومعامل التحاليل، ولوحة تحكم بإحصائيات شاملة، وصفحة لعرض كل المرضى في النظام.
- **حساب دكتور / معمل تحاليل**: كل واحد يضيف مرضاه الخاصين (اسم + رقم هاتف + سن)، ويرفع نتائج التحاليل كملفات PDF لكل مريض، مع إمكانية العرض والتحميل والحذف.
- هوية بصرية **أزرق وأبيض** بشعار مستوحى من أنبوبة المعمل.
- تسجيل دخول بالأدوار الثلاثة (أدمن / دكتور / معمل) من نفس الصفحة.

> **ملاحظة هامة**: هذا مشروع عرض توضيحي (Demo) — البيانات وملفات الـ PDF تُخزَّن في `localStorage` داخل المتصفح (لا يوجد سيرفر أو قاعدة بيانات حقيقية بعد). ده يعني البيانات محلية على جهازك/متصفحك فقط، ولو مسحت بيانات المتصفح هتتمسح. لو عايز تحويله لموقع حقيقي متعدد المستخدمين، الخطوة التالية هي ربطه بقاعدة بيانات حقيقية (مثل PostgreSQL/Supabase) ونظام تخزين ملفات (مثل S3) بدل الـ localStorage.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000` في المتصفح.

## البناء للإنتاج

```bash
npm run build
npm run start
```

## هيكل المشروع

```
app/
  page.tsx              صفحة تسجيل الدخول
  admin/                لوحة تحكم الأدمن (دكاترة، معامل، كل المرضى)
  doctor/                لوحة تحكم الدكتور (مرضاه فقط)
  lab/                   لوحة تحكم المعمل (مرضاه فقط)
components/
  ui/                    مكونات shadcn/ui (Button, Card, Dialog...)
  patients-manager.tsx   إدارة المرضى (مشتركة بين الدكتور والمعمل)
  patient-results-dialog.tsx  رفع/عرض/حذف نتائج PDF لكل مريض
lib/
  store.ts               طبقة البيانات (localStorage)
  auth.tsx                نظام تسجيل الدخول بالأدوار
```
